# MySpace GitHub 备份

最近同步：2026-08-22T14:38:49.441Z

## 内容

- `backups/content-latest.json`：可恢复的完整公开内容（页面配置、日志、生活板块）
- `backups/logs-latest.md`：便于直接阅读的最新日志
- `backups/public-config.json`：前台页面配置
- `backups/gallery.json`：生活板块记录
- `backups/manifest.json`：数量、图片文件名和 SHA-256 校验值
- `uploads/`：后台上传的图片
- `backups/history/`：按日期保留的日志快照

出于安全考虑，不备份 GitHub Token、管理员密码哈希、Session 或 `.env`。
